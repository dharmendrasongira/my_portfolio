# Dharmendra Songira — Portfolio

Personal portfolio website of Dharmendra Songira, a Junior Software Engineer working across mobile and web development.

Built with React 18 and Vite.

## Sections

- **Header** — intro, live code card, quick facts and social links
- **About** — background, current role and skill overview
- **Services** — mobile app development, web development, AI and workflow automation
- **Skills** — frontend/mobile and backend/database/tooling stacks
- **Projects** — Mock Ninja, Eduved, healthcare mobile and web platforms, AI hiring automation
- **Certifications & Achievements** — NPTEL and Infosys Springboard certifications, education
- **Contact** — email, LinkedIn and WhatsApp

## Tech stack

React.js, React Native (professionally), Redux Toolkit, Node.js, Express.js, MongoDB, MySQL, TypeScript, Tailwind CSS, n8n.

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run preview  # preview the production build
npm run lint     # run ESLint
```
